# 日语 N5 · 慢慢学

面向中文学习者的静态日语入门学习站。

**在线学习：https://muyuzumi.github.io/N5-study/**

- 五十音、清浊音、拗音、长音与促音讲解
- 788个词条（674个社区基础＋114个实用入门补充），中文释义、假名与来源例句
- 81个语法点，中文接续、用法提醒与例句
- 105个汉字（84个社区基础＋21个补充），音读、训读、部首、笔画与关联词
- 49个常用动词的活用工作台
- 18节系统讲解、18组易混对照、八周学习路线、官方考试信息
- 10篇原创阅读、8组合成语音听力训练、50道知识题与随机词汇题
- 搜索、分类筛选、收藏、掌握标记、闪卡间隔复习、错题本、进度备份／恢复

## 使用与部署

无需安装依赖或构建。将本仓库根目录部署到GitHub Pages；在Settings → Pages使用main分支、根目录。也可以下载所有文件后直接打开 `index.html`；学习记录按浏览器和访问来源隔离。

`data.js` 是与JSON一致的浏览器数据包，使直接打开HTML也能学习。更新JSON后需要同步生成data.js。首页依次加载data.js、curriculum.js、app.js；路径均为相对路径，支持GitHub Pages项目子目录。

## 学习范围和许可

JLPT官方没有公布当前版本的完整词汇、汉字和语法清单。本站覆盖社区参考范围并补充入门知识，不承诺囊括所有可能考题。部分来源例句难于N5，部分衔接句型的教材等级可能不同，均在站内说明。

资料来源、衍生修改、CC BY-SA 4.0与原句许可说明见 [DATA-SOURCES.md](DATA-SOURCES.md)。合成语音不替代官方真人听力材料。进度保存在当前浏览器，可导出JSON备份。旧站的 `n5-site-progress-v2` 已记住条目会自动迁移到新记录中。
